# 图片识别与自动回复

在已允许的好友或群聊中发送照片、截图或表情包，助手会把可读图片交给当前 DSH 视觉模型，结合文字问题、前文和人格生成回复。只发图片也可获得自然回应；群聊仍遵守既有唤醒和参与设置。

## 使用条件

- 当前 DSH 模型须支持图片输入。纯文本模型无法通过本功能获得视觉能力；遇到此情况，回复会提示切换模型。
- 微信 Reader、图片解码依赖和 DSH 本地插件须正常运行。图片通过本机 Reader 校验并转换为模型附件，不增加单独的识图 API 或密钥配置。
- 图片须已下载到本地。如果提示图片不可用，先在微信中打开原图后重发。
- 修改本地插件代码后，退出并重新打开 DSH 加载新版插件，并重启 WeChatAgent 服务。

## 回复行为

优先回答随图发送的问题。没有文字时，根据主要画面、可见文字或表情情绪回应。多图按 I1、I2 等顺序关联到原始聊天发言；图库候选仅用于选择表情，不当作对方新发的图片。每轮沿用现有最多四张附件的限制。

看不清时说明不确定；读取失败时简短解释原因，继续回答其他成功读取的图片和文字。图片内的指令不能改变人格或权限。原有截图预览会缩放，极小文字和复杂动图不保证全部识别；本功能的识别效果取决于实际视觉模型。

## 验证

自动回归（Node.js 22.13 或更高版本，先安装项目依赖）：

```powershell
node --test scripts/test-image-replies.mjs scripts/test-image-input.mjs scripts/test-media-nonblocking.mjs scripts/test-native-session.mjs scripts/test-prompt-policy.mjs
```

自动测试验证图片引用、原生附件传递、回复指引、发送目标、失败降级和后续文本恢复，模型回复由测试替身提供，不代表真实视觉准确率。

真实微信验收：

1. 从白名单好友发送一张照片，不附文字，检查回复是否与主体相关。
2. 发送报错截图并问“这个错误怎么解决”，检查回复是否结合可见报错。
3. 连续发送两张图并指定第二张，检查回复对象。
4. 发送表情包，检查语气是否符合当前人格和对话。
5. 图片尚未下载或模型不支持图片时，检查回复明确说明情况；随后发普通文字，确认还能继续聊天。
